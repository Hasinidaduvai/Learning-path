# Learning Path Generator

A Learning Path Generator that creates personalized step-by-step learning roadmaps based on a user’s goal, skill level, available time, and preferred learning style.

## Features

- Generate custom learning paths for any topic
- Break goals into beginner, intermediate, and advanced stages
- Recommend resources, projects, and practice tasks
- Track progress across lessons or milestones
- Optional automation using Pipedream or Composio

## Tech Stack

- Frontend: React / Next.js
- Backend: Node.js / Python
- AI: OpenAI API
- Automation: Pipedream or Composio
- Database: Supabase / PostgreSQL / MongoDB
